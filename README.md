## ▶️ Getting started

The current repository README recommends the following workflow:

### 1. Create and activate a virtual environment

```bash
python -m venv .venv
```

Activate it according to your operating system.

### 2. Install dependencies

The README suggests installing dependencies with:

```bash
pip install -r requirements.txt
```

or manually installing the packages used in the notebooks. The public README mentions this step, although a `requirements.txt` file is not visible in the root listing shown on the repository homepage. 

### 3. Open the notebooks

You can open the notebooks with:

```bash
jupyter notebook
```

or with your preferred IDE/editor to follow the course exercises.
